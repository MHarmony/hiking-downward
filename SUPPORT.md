# Support

## Before asking for help

Search the [documentation](README.md), existing [issues](https://github.com/MHarmony/hiking-downward/issues), and [discussions](https://github.com/MHarmony/hiking-downward/discussions) before opening a new request. Include the repository version or commit, operating system, relevant browser or runtime versions, and the exact command or steps involved.

## Where to ask

- Use the [bug report form](https://github.com/MHarmony/hiking-downward/issues/new?template=bug_report.yml) for reproducible problems.
- Use the [feature request form](https://github.com/MHarmony/hiking-downward/issues/new?template=feature_request.yml) for proposed improvements.
- Use [GitHub Discussions](https://github.com/MHarmony/hiking-downward/discussions) for questions, ideas, and community help.
- Use [GitHub Issues](https://github.com/MHarmony/hiking-downward/issues) only when no suitable form or discussion category applies.

## Security reports

Do not report vulnerabilities in public issues, pull requests, or discussions. Submit a [private GitHub Security Advisory](https://github.com/MHarmony/hiking-downward/security/advisories/new). If private reporting is unavailable, email [contact@hikingdownward.com](mailto:contact@hikingdownward.com) as described in [SECURITY.md](SECURITY.md).

## Conduct

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). Support requests should be respectful and contain enough context for others to reproduce or answer them.
